A simple Jellyfin plugin that publishes custom pages on your server at `/pages/{slug}`. These pages utilize Jellyfin's authorization to optionally gate access to only users or administrators.

<br clear="left">

## Documentation

Installation, authoring, visibility, system access, stores, assets, and security are covered in the **[Custom Pages documentation](https://jpkribs.github.io/jellyfin-plugin-custompages/)**.

Plugin repository URL for Jellyfin:

```
https://raw.githubusercontent.com/JPKribs/jellyfin-plugin-custompages/master/manifest.json
```
