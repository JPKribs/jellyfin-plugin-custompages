Assets

Upload images to host them for your pages. Reference one from a page's HTML or CSS with the path shown on its card, for example <img src="asset/logo.png"> or url('asset/logo.png'). Visibility controls who can see the image. Assets set to Anyone are served publicly at /pages/asset/{name}. Assets set to Users or Administrators are referenced the same way but are never served by URL. They are embedded into pages of an equal or higher visibility tier when the page renders.
